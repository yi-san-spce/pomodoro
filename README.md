# 🍅 番茄钟 (Pomodoro Timer)

一个简洁优雅的 Web 番茄钟应用，帮助你高效使用番茄工作法。

## ✨ 功能

- 🍅 **专注模式** — 25 分钟专注计时（可自定义）
- ☕ **短休模式** — 5 分钟短休息
- 🌿 **长休模式** — 每 4 个番茄后自动进入长休（15 分钟）
- 🔊 **音效提示** — 使用 Web Audio API 合成，无需音频文件
- 🔔 **桌面通知** — 计时结束浏览器通知
- ⚙️ **自定义设置** — 所有时长、音量均可调节
- 💾 **设置持久化** — 自动保存到 localStorage
- ⌨️ **键盘快捷键** — 空格(开始/暂停)、R(重置)、→(跳过)、1/2/3(切换模式)
- 📱 **响应式设计** — 适配桌面和移动端
- 🌙 **暗色主题** — 护眼深色配色

## 🚀 使用

直接在浏览器中打开 `pomodoro.html` 即可使用。

## ⌨️ 快捷键

| 按键 | 功能 |
|------|------|
| `空格` | 开始 / 暂停 |
| `R` | 重置当前计时 |
| `→` | 跳过当前阶段 |
| `1` | 切换到专注模式 |
| `2` | 切换到短休模式 |
| `3` | 切换到长休模式 |

## 🛠 技术

纯 HTML/CSS/JS 实现，零依赖，无需构建工具。
